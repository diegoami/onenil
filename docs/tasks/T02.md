# T02 Rust goal placement, eligibility and roster helpers

- **Kind**: slice
- **Issue**: #4 · **Branch**: `task/T02-goal-placement` · **Merge after**: archaeology T13.
- **Evidence**: archaeology F12 at `77841e9` and supplemental T13/F13 inputs; source cases,
  manifests and finding commits are pinned by digest/provenance.
- **Owns**: `engine/**`, `tools/replay_placement.py`, `records/T02/**`, `.github/workflows/**`,
  `README.md`; existing contest fixtures and timing receipts remain immutable.
- **Scope**: translate DD7C–DF35 control flow using explicit byte/word state and wrapping, with
  native 4F89 availability and 5C6E first-roster-match helpers. All 558 placement entries receive
  original complete rosters/fields, independent of whether a goal was expected. Compute repeated
  minute fills, scorer retries, selected actor, residual generated counts, cumulative local scores,
  goal flag and every RNG transition. Preserve at most one recorded goal and the score cap.
  Model 5083's verified single coin draw as its RNG projection; emit an explicit goal-effect
  request while statistics, logs and display effects remain external. Expected draw arguments,
  seeds or goal decisions cannot drive the native algorithm. Expose the same code through PyO3.
  No full DD02, ratings, clock/player-update, match/week or UI parity is claimed.
- **Milestones**: (1) original-fixture replay fails against a stub, committed/pushed receipt;
  (2) native implementation, fixtures and bridge checks; (3) final pin, timing receipt and CI.
- **Done when**:
  1. `cargo test --manifest-path engine/Cargo.toml --locked` passes all 558 placement cases,
     1,804 computed draws, 17 explicit goal calls and 12,276 original helper checks, preserving
     T01 tests. The PR records the same original-case test failing before implementation.
  2. Release `maturin develop --manifest-path engine/Cargo.toml --features python --locked`
     followed by `python3 tools/replay_placement.py --check` passes the same cases via Rust,
     verifies fixture hashes/provenance and all 15 T08 references, with negative divergence tests.
  3. `python3 tools/replay_placement.py --benchmark --out records/T02` creates a new immutable
     routine-only timing receipt from clean committed code, identifying the actual loaded binary.
  4. Formatting, original-file checks and CI pass; source fixtures are byte-identical to the pinned
     archaeology exports. Synthetic tests cover retries, duplicate IDs, caps, zero counts and
     callback/missing-input errors without claiming original dynamic coverage for those branches.
- **Hazards**: repeated fills visit both sides; signed eligibility differs from unsigned counts;
  the cumulative local score is distinct from temporary D983 counts and final global packing.
