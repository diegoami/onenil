# T04 Native ratings and computed-rating contest handoff

- **Kind**: slice
- **Issue**: #8 · **Branch**: `task/T04-ratings` · **Merge after**: archaeology T15.
- **Evidence**: F09 and T15/F15's raw-input ratings/helper contract. Copied fixtures and
  manifests are pinned by archaeology commit and digest; T01–T03 evidence remains unchanged.
- **Owns**: `engine/**`, `tools/replay_ratings.py`, `records/T04/**`,
  `.github/workflows/**`, `README.md`.
- **Scope**: translate 1B55:50EB and its player/staff/predicate helpers into the shared memory
  image with explicit guest arithmetic, aliases and selectors. Inputs are raw roster/player/
  staff fields, flags and tables, never expected predicate or rating outputs. Compute ratings
  then run the existing D983 routine using those actual image words, preserving the incoming
  seed/goals. Expose the same native path through PyO3. Keep full-step setup/clock/events and
  full DD02/match/week, watched-engine, timer and renderer parity outside this slice.
- **Milestones**: (1) a real original-case replay fails at a stub, receipt committed/pushed;
  (2) native routines, helper and composed original replays; (3) final pin, timing and CI.
- **Done when**:
  1. `cargo test --manifest-path engine/Cargo.toml --locked` passes all 1,128 original side
     cases, recorded helpers and 558 computed-rating D983 handoffs. The PR records the same
     real-fixture test red before implementation. Synthetic checks cover signed bytes, clamps,
     division/wrapping, predicate branches, flags/classes, missing/aliased IDs and errors.
  2. A release maturin build followed by `python3 tools/replay_ratings.py --check` verifies all
     original cases/helper outputs and 15 T08 references, source hashes/provenance, and actual
     computed ratings→D983 draws/results without resetting handoffs to expected values.
  3. `python3 tools/replay_ratings.py --benchmark --out records/T04` writes a new immutable
     routine timing receipt from clean code, naming actual binary/build settings.
  4. Formatting, original-file checks and final-head CI pass; copied evidence is byte-identical
     to T15 exports and prior T01–T03 fixtures/provenance/timing remain byte-identical.
- **Hazards**: helper outputs belong in assertions only; preserve native shared seed and image,
  use signed and unsigned operations at the original widths, and label unobserved branches.
