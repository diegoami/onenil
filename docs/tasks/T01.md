# T01 First Rust engine slice replays quick-contest traces

- **Kind**: slice
- **Issue**: #2 · **Branch**: `task/T01-quick-contests` · **Merge after**: archaeology T11.
- **Evidence**: onenil-archaeology F02 (RNG), F07 (D983), F09 (rating layout) at `7859d7d`, and
  T11/F11's recorded routine contract. Findings and fixture inputs are pinned by commit/digest.
- **Owns**: `engine/**`, `pyproject.toml`, `.github/workflows/**`, `tools/replay_contests.py`,
  `records/T01/**`, `README.md`, dependency lock files.
- **Scope**: the first executable Rust slice: D983 and the generator it calls, using one memory
  image with explicit byte/word accessors and wrapping arithmetic. A PyO3 extension exposes the
  same Rust routine to Python; maturin builds it in CI. Copy only T11's decoded fixtures and
  manifest, with archaeology provenance and digests; replay every routine call and expected draw,
  checking the argument, seed transition, returned value, site and final goal bytes/seed. The
  manifest must account for all 15 T08 traces (six distinct weeks). Tests identify the first
  mismatch and include a changed expected draw/input as a negative check. No Python engine model,
  ratings computation, full match/week, watched engine or UI enters this task.
- **Milestones**: (1) crate/test scaffold with a demonstrated failing replay;
  (2) faithful routine, fixtures and Python bridge; (3) validation and initial slice timing receipt.
  Commit/push at each and checkpoint on this issue.
- **Done when**:
  1. `cargo test --manifest-path engine/Cargo.toml --locked` passes all 558 original routine cases,
     and the PR records the same replay test failing before the routine was implemented.
  2. After `maturin develop --manifest-path engine/Cargo.toml --features python --locked`,
     `python3 tools/replay_contests.py --check` passes through the Rust bridge, verifies fixture
     digests/provenance and reports all 15 source traces covered.
  3. `python3 tools/replay_contests.py --benchmark --out records/T01` writes a new immutable timing
     receipt naming code, platform, fixture counts, repetitions and elapsed time; no speed threshold.
  4. `cargo fmt --manifest-path engine/Cargo.toml -- --check`, `python3 tools/check_originals.py`
     and CI pass; fixture bytes match the pinned archaeology exports.
- **Hazards**: signed CMP/JLE versus unsigned RNG multiplication; zero chances still returns without
  draws. A passing routine replay does not establish full O-M3a completion or Rust match parity.
