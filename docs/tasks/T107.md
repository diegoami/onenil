# T107 A warning-free release build

- **Kind**: infrastructure · **Issue**: #208 · **Branch**: `task/T107-warnings`.
- **Evidence**: [confirmed:#100 milestone review; reproduced on ec4611b] a clean
  `cargo check` of the desktop build reports **48 engine warnings** plus two test
  warnings: 35 `unused_mut`, 6 `unreachable statement`, four unused
  imports/variable, and four dead items (`sar`, `copy_within`, `PITCH_CELLS`,
  `from_legacy`). Nearly all sit in `engine/src/watched_compiled/*`, which
  `tools/compile_watched.py` generates, so fixing them there is the durable fix
  rather than editing generated text.
- **Owns**: `tools/compile_watched.py`, the regenerated
  `engine/src/watched_compiled/*.rs`, the four hand-written items, the two test
  files, and the workflow's Rust checks.
- **Scope**: [designed] remove every warning instead of hiding them: emit the
  unported-instruction error as the end of its basic-block arm (the six
  unreachable `c.pc` lines), emit `let` rather than `let mut` when a procedure
  never assigns its label, and mark the generated module globs
  `#[allow(unused_imports)]` with the reason. Delete the four provably unused
  items or annotate the ones only their own tests use. Fix the test warnings.
  Regenerate the compiled modules with the committed script and keep `--check`
  byte-identical in meaning. Finally gate it: the workflow's Rust checks run
  with warnings denied, so the count cannot creep back.
- **Milestones**: frozen task; generator fix and regeneration; hand-written and
  test fixes; warning gate; engine/desktop suites and exact-head CI; pinned squash.
- **Done when**:
  1. `RUSTFLAGS=-Dwarnings CARGO_BUILD_JOBS=4 cargo check --manifest-path desktop/faithful/Cargo.toml --locked --all-targets`
     passes with no warning, and the same holds for the campaign crate.
  2. `python3 tools/compile_watched.py ... --check` still reports the committed
     compiled modules unchanged, and the engine's replay tests pass - no byte of
     emitted behaviour changes, only dead text and mutability.
  3. Exact-head CI (with the warning gate) passes before the pinned squash.
- **Hazards**: deleting a statement the generator emits can change behaviour if
  it is reachable; only the arms after an unconditional `return Err` may go.
  Never silence a whole generated module with `#![allow(dead_code)]`. Host-wide
  ps/free before builds, one Rust build at a time with `CARGO_BUILD_JOBS=4`.

[amended on main, 2026-11-21] The generator fix was reverted during the task: the
compiled graphs are pinned evidence (CI regenerates `interval_graph.rs` byte for
byte, `records/T83/graph.json` pins `post_match_graph.rs` and the reused
`action_graph`/`match_graph`, and T35/T39/T40 pin those files too), so their 44
artefact warnings cannot be rewritten without invalidating records. Done-when 2
is met by leaving every generated byte unchanged; the warnings are allowed once
per module declaration in `watched_compiled/mod.rs` with that reason, and the
hand-written and test fixes plus the `-Dwarnings` gate are as planned.
